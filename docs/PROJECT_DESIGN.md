# Awesome Academic Figures：设计方案

本文件记录当前实现及后续方向。截至 **2026-10-01**，统一画廊收录 **3,000 幅图，来自 2,174 篇去重后的论文**。其中 **21 幅有已核实的获奖标签**，3,000 幅均有宏观布局标签。本轮素材下载与目录检查在 GitHub Actions 云端执行；本机保留前端、元数据和滚动小预览。最终库存以 `data/catalog.json` 和各图元数据为准。

## 名称与定位

仓库名：`Awesome-Academic-Figures`。展示名：**Awesome Academic Figures**。

定位是为自己的论文寻找图形参考：用户可以上传论文文字或 PDF 获取参考建议，也可以按图形类型浏览，再把图片、来源、结构描述、prompt 和用户任务交给绘图智能体。

获奖是有官方证据的论文标签和可选筛选条件，不是收录前提。普通论文、获奖论文、首图和方法图共用同一画廊，来源与核验状态分别保留。Oral / Spotlight 是报告形式，不能冒充获奖标签。

用户最初指定的重点仍是正文 Figure 1 与 Figure 2。18 幅精选保留已核实编号；扩展来源的首图和方法图在编号未知时不会加入 Figure 1 / 2 筛选，也不宣称已经核实正文或附录位置。

## 两种找图入口

**从自己的论文出发。** 点击“用我的论文找参考图”，上传 PDF、TXT、Markdown，或粘贴标题、摘要和方法描述。上传后自动给出候选；粘贴后点击匹配。研究者查看匹配理由和实际抽取的文字，打开原图核实，选作参考，再带入绘图任务和 ZIP 导出流程。

**从图形形式出发。** 默认维度为图形类型，支持框架图、流程图、概念示意图、定性展示、数据图、多面板组合、分类层级图与研究概览。还可切换用途、布局、论文来源，并叠加会议、年份、已知图号、获奖标签和关键词筛选。底层使用同一份图像索引，筛选不会清空本次选图。

卡片显示完整图像、简短浏览标题、会议年份和图号状态；完整论文题目放在详情中，图号不在标题里重复。统一媒体容器使用 contain，不因卡片尺寸裁掉内容。图库中出现的实际来源裁剪错误需要通过审核排除，不能靠前端容器掩盖。

论文档案展示完整标题、作者、来源、论文集发布日期、arXiv 链接与首次提交日期、图鉴收录日期。不同日期分别显示，缺失日期不根据年份推断。详情中保留许可 URL、来源版本、图像提取方式和描述验证状态。

## 已实现的论文推荐

当前推荐是**浏览器内可解释的关键词与主题排序**，不调用大模型匹配 API，不声称实现全文深层语义理解或保证找到客观上最合适的图。

匹配信号包括：论文标题关键词、中英文主题同义词，以及图的类型和用途。主题覆盖大语言模型、视觉、强化学习、扩散、图学习、医学与生物、多模态、智能体、机器人、检索增强、知识编辑、视频、三维、语音和优化效率。每个结果显示共同主题、命中的标题关键词和可用的用途理由；同一篇论文最多展示两幅推荐，减少重复候选。

用户直接选择想画的图类，默认 Teaser 图（研究概览），可切换机制图、方法框架图、流程图、概念示意图、对比图、数据图、数据集 / 评测图与多面板图。图类选择严格限定推荐候选；Figure 1 或论文首图位置不能单独作为 Teaser 依据。类别不足或主题无匹配时显示恢复提示，不混入其他图类。所选图类同时进入推荐理由与智能体任务说明。分类未经过人工核实的条目只提供初步建议，用户需要查看图像确认。

PDF 通过 PDF.js 在浏览器内抽取文字，解析组件和同域 worker 按需加载。文件限制 **20 MiB**、PDF 前 **40 页**、最多 **120,000 个字符**，界面显示实际读取页数与截取状态。摘要、方法和前段文字优先参与排序，识别到参考文献标题后排除后文。用户可查看、修改实际抽取的文字，修正提取顺序或加入具体术语。

扫描件或没有足够可提取文字的 PDF 提示用户先用自己的 OCR 工具转成文字，再上传 TXT / Markdown 或粘贴摘要；本版本不提供 OCR。密码保护、损坏、格式不支持或过大文件有明确恢复提示。替换上传失败保留原文和建议；清空会取消当前解析并丢弃匹配文档，过期解析结果不会覆盖新输入。

论文文字和上传文件仅在浏览器内读取。匹配文字不进入 URL、持久化浏览器存储、后台或匹配 API。关闭匹配窗口释放其文档状态；用户主动带入的任务留在应用内存，随后可自行下载 ZIP。图库图片按需从 GitHub 加载，论文内容不随图片请求发送。

## 分类与挑选

每图记录主要类型和可用的辅助标签。图形类型、用途、布局与来源相互独立：同一字段多选为“或”，不同字段之间为“且”。分类缺失或未经逐图核实的状态保留，不虚构布局或用途来填满筛选项。

`加入项目` 打开明确的项目去向选择，勾选保存；同一张图可进入多个项目，移出其中一个不影响其他项目。新用户不自动创建默认项目。`Star / 收藏` 保存长期个人收藏。`暂时隐藏` 减少当前挑选过程的干扰，已隐藏列表可以恢复；恢复不自动收藏或选中。

项目配置、图 ID 和收藏保存在当前浏览器，隐藏在当前会话保存，不承诺账号或跨设备同步。存储不可用时使用内存并给出提示。论文文字和任务内容不进入这些偏好存储。

导出前填写研究任务、模块 / 关系或数据、需要借鉴和改变的部分。论文推荐入口可把论文片段、匹配理由和选中的参考带入这一步。图像和描述逐一对应，避免把多张图压成一张低清拼图作为唯一交付。

来源索引核对、数据集行级许可检查和逐图人工审核是不同状态。批量图像有抽样报告与已知问题排除记录，**不能声称全部 3,000 幅都经过独立逐图人工审核**。已识别的裁剪缺失、素材 / 标志单独权限疑问及重复图不进入公开图像目录。

官方获奖论文清单另记录 156 篇论文及覆盖状态，用来跟踪会议年份进度，不等于全部已发布论文，也不代表这些论文图片都可转载。各会议年份和正文 Figure 1 / 2 仍为部分覆盖，不声称遍历完成。

## 图像、Prompt 和参考包

对 arXiv 源码精选，保留具体版本、作者原文件的原路径与 SHA-256、图注和可用的 TeX 排版片段。单个图 PDF 只转换为网页预览，原矢量文件保留。多面板图需要完整组合核对，独立子图不能替代完整 Figure。

对扩展图源，保存的是上游提取、渲染或按训练分辨率整理后的 JPEG / PNG，**不是作者原始矢量文件或绘图代码**。保留入库图像字节与校验值，不虚构缺失的 SVG、PDF、TikZ 或作者脚本。准确图号和图注缺失时明确记录未知。

参考包包含参考图片、元数据、来源 / 署名 / 许可、提取记录和可用的结构描述、prompt 与智能体任务模板。具备作者原文件的精选图另外包含原文件与排版片段。网页导出核验所提供的来源文件 SHA-256；缺失或不一致时保留任务输入并提示重试。

Prompt 分为视觉结构描述、可替换的适配模板和用户任务。首批维护者重建的 prompt 未声称来自作者，也未经过实际改绘生成验证。批量首图的通用模板和 SciForma 的机器生成描述明确保持草稿 / 未验证状态，不称为独立人工审核后的复现指令。

智能体应替换为用户自己的方法名称、模块、关系、真实数据与可使用的实验图片。实验曲线或统计图需要用户真实数据；示例数据若以后提供必须显式标注。实际生成代码和改绘示例是后续方向，当前不声称每图已有可复现绘图代码。

## 授权与存储

公开图像必须有对应资源和版本的明确再分发依据。当前采用已核验的 CC BY 4.0 / CC0 等既定许可检查规则；其他协议单独审核。arXiv 的 nonexclusive-distrib 不作为画廊转载依据，上游仓库 MIT 也不覆盖论文图片。第三方照片、标志、截图或模型素材具有单独权利时另行核查。

许可不明确的记录保留元数据和来源链接，不提供其图像。代码与维护者原创文字使用 MIT，图像、作者原文件与引用图注保留各自协议。每图保留署名、许可 URL、出处、固定版本和转换说明。

本轮批量素材在 GitHub Actions 云端 runner 收录，缓存不进入公开 Git；历史 SSH 收录流程保留。本机用于代码、元数据和轻量预览，不镜像批量图像或整篇论文 PDF。图片在用户浏览、选图和导出时按需读取，参考包由浏览器为所选条目生成。

## 后续方向

后续可增加语义模型检索、按参考图寻找相似布局、颜色与长宽比筛选、独立贡献流程及经过实际生成验证的改绘示例。这些是设计方向，当前已实现的推荐仍是本地标题 / 主题 / 图类匹配。

覆盖扩展继续记录具体来源与许可，逐步补充准确图号、图注和完整性核对。获奖标签作为同一画廊的补充证据，不恢复为单独库或收录门槛。

## 人与智能体共用的项目

README 面向研究者，AGENTS.md 面向智能体。scripts/agent.mjs 共用网页检索和项目模型，提供 JSON 输出的 search / describe 与 project list / show / create / configure / add / remove。浏览器的「项目与智能体」面板导出轻量配置，导入时先核对，再按项目 ID 更新，保留其他项目。没有账号后台或自动同步；选中素材才按需读取图片。agent.json、llms.txt 和 project-schema.json 提供发现入口与格式契约。
