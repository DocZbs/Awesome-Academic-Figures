# 五维任务复杂度与基准评测全景图

画面由四个彩色描边的大区和中央放射轮盘组成。左上绿框标题为 Controllable Task Complexity Across Five Dimensions，按 Level 1–3 与 Dependency、Branch、Instruction、Knowledge、Hierarchy 排列节点树、分支和简化知识图，另有小雷达示意。中央 OmniBench 轮盘用内外扇区、类别名、小图标与数字组织 Planning、Long Context、Decision Making、Generalist Knowledge 等能力；这些数值不能作为改绘的新基准数量。

右上红框 High-Quality Graph-Based Data 包含任务节点图、Task Instruction / Task Intent / Task Trajectory 文字以及小条形对比图。左下蓝框为综合评测，包含四类任务能力的举例、横向条形图和雷达图。右下黄框结合自动基准构建小流程、Desktop/Mobile/Web 平台示意与真实任务场景网格。中心轮盘与外围区域的接触表示主题联系，不宜一律解释成串行数据流。

主要类型从单一conceptual修正为多面板，附加分类体系、数据图、概念图。用途为基准/数据集概览，辅以方法介绍和对比；布局是四区网格、中心放射与嵌套分区。五个高层视觉区域的计数包含中央轮盘，不是五个已核正式子图。

适合借鉴同一基准的“能力定义—任务构建—评测—应用覆盖”全景组织。应替换维度、难度层级、任务图、构建步骤、平台类别和真实统计结果；没有实测数据时不画虚构条形图/雷达分数。参考包含商业软件/模型标志，改绘用自绘通用图标，不临摹装饰标志。部分小字和统计口径不可可靠转录。配色只是从预览估计，未核全文、正文图号或原分辨率裁图；prompt已做视觉/文字审核，改绘仍未生成验证。
