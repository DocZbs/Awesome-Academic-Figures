MAGN structure. Schematic structure of the Multi-Associative Graph Network (MAGN). Sensory fields (rectangular nodes A and B) contain sensory neurons representing unique feature values (green circles), each with an associated duplicate counter indicating how many times the value appeared in the training data. Object neurons (blue circles) represent individual data samples and are linked to the sensory neurons through defining connections, which encode the feature composition of each object. Similarity connections between sensory neurons capture statistical associations between feature values across the dataset, while duplicate counters on object neurons reflect the frequency of feature values and their patterns. Together, these components form a hierarchical associative graph that enables incremental learning, relational reasoning, and efficient retrieval.
