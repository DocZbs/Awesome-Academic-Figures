# 具身基准的任务层级与能力评测概览

横向画布内两大栏。左栏上半是 High-level Household，含 EB-ALFRED 与 EB-Habitat，下面两块分别是 Low-level Navigation、Low-level Manipulation；每个任务块都有场景小图和指令。右栏为 2×3 能力卡片：Base Capability、Spatial Awareness、Common Sense、Visual Appearance、Complex Instruction、Long Horizon，卡片内为场景和文字气泡。顶部还有高层动作/低层向量对照、基准名称及模型标志。整体讲清基准覆盖范围，故属 Teaser 与数据集组成；不是神经网络结构或机制详解。
