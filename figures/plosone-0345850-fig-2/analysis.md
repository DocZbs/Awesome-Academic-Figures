Operating principle of all-optical ReLU function using phase-sensitive nonlinear processes in a doubly-resonant cavity. (A) For positive inputs (phase ϕ = 0 ), constructive interference between resonant 2 ω and SHG-generated 2 ω within the χ ( 2 ) region results in an amplified second-harmonic output. (B) For negative inputs (phase ϕ = π ), destructive interference suppresses the second-harmonic output due to phase cancellation.
