# 多种输入汇聚到生成器并分发任务

左侧四类输入沿彩色曲线汇入中央 VideoPoet：文本、图像、深度与光流、遮罩视频。右侧从模型分出文本到视频、图像到视频、风格化、外扩和视频到音频等输出；最右侧是一组生成示例。整体是横向的输入—核心模型—输出结构，颜色让不同模态便于追踪。改绘适合表达统一模型的多种能力，输出任务和示例必须确实存在。
