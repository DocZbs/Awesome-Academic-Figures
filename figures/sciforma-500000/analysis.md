# 分支叙事树的递进展开机制

三个横向快照展示同一叙事树的展开。第一阶段是四个纵向节点；第二阶段从根节点分成两条四层路径；第三阶段在左侧第二层节点再扩出第三条路径。两个粗水平箭头表示阶段递进，树内细箭头指向下一情节。圆形节点用带上下标的 p 标识，无定量坐标轴、无结果曲线。

主类：taxonomy。布局：left-to-right。颜色为目测近似。
