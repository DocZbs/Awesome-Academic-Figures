# 图文生成质量的点标注与评分界面

左侧是一张生成的熊猫骑摩托车图，红色点标出视觉缺陷，青色点标出与文本不一致的位置。右侧显示 prompt 中被选中的词，以及合理性、图文一致性、美感、总体质量四组评分。图像与评分紧密并排，所选词和评分用下划线强调。改绘可借鉴“例图＋可定位反馈＋分项评分”的结构，示例图片与评分必须由自己的材料提供。

## 来源与核对

Rich Human Feedback for Text-to-Image Generation，CVPR 2024，Figure 1。原文件：fig/MAXO-GEN-annotation3.pdf。版本：2312.10240v2。

已核对独立图注编号、完整原文件及预览。作者原文件按字节保留；PNG/WebP 仅用于浏览。颜色是维护者近似读值。改绘 prompt 为维护者重建，尚未实际生成验证。
