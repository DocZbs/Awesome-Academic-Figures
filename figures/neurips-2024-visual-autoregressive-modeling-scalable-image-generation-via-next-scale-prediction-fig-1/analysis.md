# 生成样例、分辨率层次与编辑序列

上方四张较大的生成图形成主视觉，中间一排较小的样例扩展主题多样性，底部两组细长序列展示零样本图像编辑。不同尺寸的行形成“主结果—更多结果—任务变化”的层次。适合生成模型的首页样例图，实际结果必须来自自己的模型，并写清分辨率、输入、编辑操作和筛选规则，不能用生成工具补出实验结果。
