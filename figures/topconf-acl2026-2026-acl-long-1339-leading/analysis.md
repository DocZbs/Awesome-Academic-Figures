# MoRE / Social-Evol：道德类型、认知架构与社会演化环境

上方大矩形标题为 Agent Cognitive Architecture (MoRE)。左侧 Moral Types 嵌套四层浅色卡片，能读出 Universal Moral Agents、Reciprocal Moral Agents、Kin-focused Moral Agents 与 Selfish Agents，各有短行为说明和人物小图。中间上沿为淡紫色 Reflection，列出关于道德类型、记忆更新、回应格式与计划的反思问题。其下左侧是 Immediate Action Plan，含 Short-term Action Planning 和 Current Action Choice，二者由向下箭头连接；右侧较宽区域是 Entity-based Memory, Judgement and Disposition Processing，按列排 Reproduction/Family/Other、Agent-specific 和 Hunting 模块。右侧 Perception 竖列由 Plants & Prey、Agent Status、Recent N Steps Activities 三张绿色卡片组成，箭头向左指向认知区。Moral Types 也向中部送入信息，规划区向上连到 Reflection。

下方大块 Environment 用两幅相邻场景插画表达活动。左画有 Allocate、Communicate，右画有 Reproduce、Fight、Rob、Collect、Hunt；中间用 Multi Coordination Round 的弯箭头和 Action Round 的箭头联系。最右 Temporal Dynamics 显示 HP drops 与 Plants/Prey Respawn。上方动作从认知区向下进入环境，环境动态沿右边向上返回 Perception，构成可见感知—行动反馈。左下另有 Simulation Analysis Assistant Agent 方框，包含报告、统计、Figures/Tables、Interactive Q&A、Code Copilot；来自环境的左向箭头标注 Simulation Results、Agent logs、Checkpoints。

保留 architecture 主类，补 flowchart 和 multi-panel。用途 method-overview、experimental-setup；机制标签来自明确的感知、计划、执行、动态回流流程，不意味着已经验证论文中所有因果含义。nested-modules 与 feedback-loop 比笼统的横向流程更准确；布局包含上下架构—环境层和左侧分析支路，不能压成一个 left-to-right 标签。

可改成仿真系统总览、智能体感知—规划—行动系统，或与环境耦合的实验平台图。替换道德/角色类型、反思问题、记忆字段、环境动作、回合过程及日志产物。插画建议用自绘抽象角色与用户许可场景，避免复制源人物形象。框内少量细字/省略号只说明字段结构，不补成作者未写的算法。此分析仅基于预览像素，未读全文、确认正式会议版图号或测试改绘；颜色为近似。
