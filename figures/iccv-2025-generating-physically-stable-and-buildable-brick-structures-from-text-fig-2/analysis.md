# 生成、有效性检查与稳定性回滚流程

上半部分左右排列结构 token 化和训练两个面板；下半部分展开推理过程，用一串积木状态图表现逐步生成。绿色勾表示有效，红色叉表示碰撞或非法积木，弧形箭头表示重采样，顶部回路表示稳定性检查失败后的回滚。适合带约束和纠错的生成方法。改绘时区分局部有效性检查与最终全局稳定性检查，不要把两类失败混在同一条回路里。
