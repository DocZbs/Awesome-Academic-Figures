# 四个质量维度的并排评分分布

四张直方图横向共用基线，依次展示合理性、一致性、美感、总体质量的评分分布。每个评分区间使用一致的颜色序列，最外侧标出计数轴；分组名称直接写在下方。适合一眼比较不同指标的分布形状。改绘必须固定相同的 bin 边界和计数尺度，避免为了让分布更漂亮而改动数据。
