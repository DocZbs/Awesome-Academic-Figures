# 层级特征金字塔与单尺度表示对比

左右两列用相同视角的透视平面比较两种表示。左列从底部密集局部窗口逐级合并为更粗的特征图，右列保持相同尺度；上方用箭头标出分类以及密集任务出口。红色边框表达窗口范围，灰色细网格表达 patch。改绘可借鉴“同一输入、不同层级结构”的对照，层数和尺度标注应使用自己的网络参数。
